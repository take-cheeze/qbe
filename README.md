# qbe (mirror)

Mirror of the QBE compiler backend, https://c9x.me/compile/ (git: https://c9x.me/git/qbe.git).

- `master` and tags are synced from upstream daily by `.github/workflows/sync.yml`
  (also runnable on demand via *Run workflow*). Fast-forward only.
- `main` only holds the sync workflow; don't build from it.

Used as the `3rd/qbe` submodule of [take-cheeze/nfcxx](https://github.com/take-cheeze/nfcxx).
